# PlanTeller Web

Statische Landingpage mit Rechtsseiten fur die PlanTeller-App.

## Dateien
- `index.html`: Landingpage
- `datenschutz.html`: Datenschutzerklarung
- `agb.html`: AGB
- `impressum.html`: Impressum
- `ki-hinweise.html`: KI-Hinweise und Transparenz
- `hinweise-disclaimer.html`: Hinweise und Disclaimer

## Assets austauschen
- Ersetze `assets/images/impression-hero.svg` und `assets/images/impression-1.svg` bis `impression-3.svg` durch echte App-Screenshots.
- Lege die Logo-Schrift in `assets/fonts/` ab:
  - `Rosehot-Regular.woff2` (empfohlen)
  - optional `Rosehot-Regular.woff`

## Lokal testen
Einfach `index.html` im Browser offnen oder einen statischen Server nutzen.
